PRÁCTICA 4 - PÁGINA WEB CON BOOTSTRAP

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server o directamente en el navegador.
3. La página incluye:
   - Plantilla/estilo Quartz de Bootswatch.
   - Barra de navegación responsive.
   - Carrusel con dos imágenes.
   - Lista (list group) centrada y de 8 columnas en pantallas medianas.
   - Tres tarjetas en 12 columnas para móvil y 4 para md en adelante.
   - Sección de 9 y 3 columnas.
   - img-fluid y rounded-top.
   - Dos botones: primary y outline-dark.
   - Formulario centrado con form-control.
   - Diseño responsive para celular/tablet.

Las imágenes son SVG locales para que la práctica funcione sin tener que buscar imágenes adicionales.
